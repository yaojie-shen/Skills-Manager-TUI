Tags classify skills. Presets save an explicit set of skills.

## Classify skills with tags

```sh
skills tag add hello-skill writing example
skills tag list hello-skill
skills list tag:writing
skills tag remove hello-skill example
skills tag set hello-skill writing
```

`skills tag set` replaces every tag on the skill. `skills tag rename OLD NEW` merges members if `NEW` already exists. `skills tag delete NAME --yes` removes the classification and all memberships, but not the skills.

## Save a deployment set

```sh
skills preset create writing-kit --description "Writing helpers" --tag writing
skills preset show writing-kit
skills preset add writing-kit hello-skill
skills preset deploy writing-kit --agent claude --dry-run
skills preset deploy writing-kit --all-agents
```

`--tag writing` copies the tag's current members once. Later changes to the tag do not update the preset. Use `skills preset add` or `skills preset remove` to change its members; both accept skill keys or `--tag`. `skills preset create` also accepts repeated `--skill KEY` options.

<DocsTuiCapture frame="presets" caption="The Presets view shows each preset's fixed members." />

Deploy and undeploy require repeatable `--agent AGENT` values or `--all-agents`.

Preview removal before applying it:

```sh
skills preset undeploy writing-kit --agent claude --dry-run
skills preset undeploy writing-kit --all-agents
```

`preset delete NAME --yes` removes only the preset definition. It does not remove installed skills or existing deployment links.

## Use Tags and Presets in the TUI

Both pages show a group panel and a skill panel. `a` opens Actions; `m` enters multi-select; `Ctrl+A` adds the current results without clearing earlier selections.

Tag-picker changes apply immediately, so `Esc` closes the picker without reverting them. Dialogs for staged membership changes provide Apply and Cancel. Preset tag coverage describes the saved members; it is not a live tag query.

## Storage and migration

Set `tags_enabled = false` to hide tag classification and disable tag commands without deleting tag or preset data. The TUI command palette and `Ctrl+O` expose the same confirmed toggle.

Each tag lives in its own `.skills-meta/tags/<tag>.toml` file. Presets live in `.skills-meta/presets/<name>.toml` and store their skills explicitly. Duplicate skill keys are deduplicated.

Opening tags or presets written by an older version upgrades them first: tags move out of `config.toml` into their own files, and presets that list tags get those tags' skills as fixed members. Skills Manager reports the backup directory; keep that backup until the resulting membership is confirmed. See [metadata format upgrades](../configuration/#metadata-format-upgrades).
