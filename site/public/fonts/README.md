# Font sources

`npm run dev` and `npm run build` download the font binaries in this directory when they are missing or fail checksum validation.

| Output | Pinned source | License |
| --- | --- | --- |
| `Silkscreen-Regular.ttf` | [googlefonts/silkscreen commit `206ccf3`](https://github.com/googlefonts/silkscreen/tree/206ccf3f5234c281461e63ecc59cbc6b0563472b) | SIL Open Font License 1.1 (`Silkscreen-LICENSE.txt`) |
| `JetBrainsMonoNerdFontMono-Regular.ttf` | [nerd-fonts `v3.4.0`](https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/JetBrainsMono/Ligatures/Regular) | SIL Open Font License 1.1 (`JetBrainsMono-LICENSE.txt`) |
| `JetBrainsMonoNerdFontMono-Bold.ttf` | [nerd-fonts `v3.4.0`](https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/JetBrainsMono/Ligatures/Bold) | SIL Open Font License 1.1 (`JetBrainsMono-LICENSE.txt`) |

Pinned URLs and SHA-256 checksums are defined in `scripts/fetch-fonts.mjs`.
